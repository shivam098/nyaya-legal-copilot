# Tools and integrations

- **Channels:** WhatsApp, app/web, IVR; Indic speech via Bhashini/Sarvam.
- **Courts:** [[ecourts]] (CNR tracking, orders), [[e-daakhil]] / e-Jagriti (consumer).
- **Grievance:** National Consumer Helpline, cybercrime.gov.in, RTI, CPGRAMS.
- **Corporate:** [[mca21]] (master data, SRN status), GST, Startup India, IP India.
- **Utilities:** OCR for orders (handwritten/Hindi), reminders, DigiLocker.
- **Legal aid:** [[nalsa-dlsa]].

Portal actions always need user approval ([[filing-agent]]).
