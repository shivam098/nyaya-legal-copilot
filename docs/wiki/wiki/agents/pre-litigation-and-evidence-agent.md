# Pre-litigation & day-zero evidence agent

Runs FR-0 ([[day-zero-evidence-and-pre-litigation]]) alongside [[fact-finder]] and [[strategist]].
- Triggers immediate 48-hour preservation notices (CCTV, call logs, raw chat exports) and generates **BSA 2023 s.63 certificates** ([[bns-bnss-bsa]]).
- Executes fast-track pre-litigation routes (RBI/Insurance/Telecom ombudsmen, chargebacks, [[tools-and-integrations|NCH / INGRAM]], corporate nodal officers) before court filing.
