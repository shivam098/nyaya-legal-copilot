# Strategist
- Builds and continuously revises the case plan using the [[scoring-objective]].
- Generates options from playbooks; consults [[courtroom-tactician]], [[settlement-advisor]], [[researcher]].
- Every option is attacked by the [[opposition-analyst]] before recommendation.
- Output: next move + reasons + citations + confidence + fallback ([[strategy-loop]]).
