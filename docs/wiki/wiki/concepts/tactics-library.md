# Tactics library

Spec: FR-9.2 in [[legal-copilot-spec-v0.5]]. Owner: [[courtroom-tactician]] (and [[corporate-counsel]] for corporate tactics).

## Record format
| Field | Meaning |
|---|---|
| Trigger | Stage/event that makes it relevant |
| Forums | Where it applies, incl. state/bench variation |
| Move | What to do |
| Script | What to say or file, in plain language |
| Legal basis | Statute/rule/judgment, if any |
| Success signals | How to tell it worked |
| Risks | When it backfires |
| Source & review | Contributing practitioner, reviewer, last verified |
| Observed effectiveness | From user-reported outcomes ([[learning-loop]]) |

## Seed tactics
- [[hearing-date-compression]] (first to ship).
- Object to repeated adjournments; seek costs.
- Close the right to reply after the statutory deadline ([[consumer-commissions]]).
- Serve copies in advance so "not received" can't justify an adjournment.
- Check the cause list the day before; stay until the matter is called.
- Get order copies the same day; file written arguments early.
- Settlement at peak leverage ([[settlement-advisor]]).
- Corporate: resubmission replies the RoC accepts first time; filing in the right order; catch-up filings before condonation ([[company-law-and-compliance]]).

## Sourcing
Practitioner interviews per forum; patterns mined from daily orders; user-reported outcomes; lawyer review before release.
