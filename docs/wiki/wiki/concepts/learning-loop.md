# Learning loop

- Track each recommendation and its actual outcome (e.g. was the nearer date granted? was the resubmission accepted?).
- Lawyer review of disagreements and failures.
- Update playbooks and [[tactics-library]] effectiveness scores.
- Build an evaluation set from real case trajectories: "at stage X, what did the winning lawyer do?"

This dataset is the moat — see [[competitive-landscape]]. Measures: [[success-metrics]].
