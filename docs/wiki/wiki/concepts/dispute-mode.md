# Dispute mode

Litigation and complaints, for complainants and respondents alike, across every forum in [[forums-map]].

Almost every Indian case passes through the same skeleton: filing → notice → reply/written statement → rejoinder → issues → evidence → arguments → judgment → appeal → enforcement. What differs is the procedure pack per forum ([[knowledge-layer]]).

Driven by the [[strategy-loop]] with [[strategist]], [[opposition-analyst]], [[hearing-coach]], [[courtroom-tactician]].

Corporate disputes from [[advisory-mode]] (co-founder fights, unpaid dues, oppression) switch into dispute mode — see [[nclt-and-ibc]].
