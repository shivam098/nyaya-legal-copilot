# Hearing-date compression

**Origin:** [[2026-10-24-practitioner-tip-hearing-dates]] — hearings a month apart in the founder's consumer case; a practising lawyer said a solid, logical reason for a nearer date is often accepted. Self-represented litigants never know to ask.

## Grounds the agent evaluates
- Statutory disposal targets: CPA 2019 s.38(7) (~3 months from notice, 5 if testing) — [[consumer-protection-act-2019]]; NI Act s.143(3) (~6 months) — [[ni-act-1881]]; DV Act s.12(5) (~60 days from first hearing) — [[dv-act-2005]].
- Adjournment limits: CPC Order XVII Rule 1 (≤3 per party) — [[cpc-1908]].
- Case age vs target (computed by [[rule-engines]]).
- Little work left (only arguments; one short witness).
- Hardship: senior citizen, medical, continuing loss, travel distance.
- Readiness: offer to file written arguments in advance.

## Output
- Respectful script in the user's language, e.g. *"Sir/Ma'am, notice was served on <date>; the Act contemplates disposal within 3 months and we are at <N> months. Only arguments remain. I request a date within 7–10 days; I'll file written arguments in advance."*
- Target date window; willingness to take a short or end-of-board slot.
- If refused: ask that the request be recorded; then early-hearing application; later, higher forum for a direction for expeditious disposal.
- Etiquette: ask once, clearly, with reasons; never argue with the bench.
