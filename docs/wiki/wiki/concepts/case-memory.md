# Case memory

Not chat history — a structured record:
- Parties, claims, facts ↔ supporting evidence.
- Documents, orders, hearings, deadlines.
- Every recommendation and why it was made (event-sourced, so past advice is explainable).
- In [[advisory-mode]]: company profile, officers, capital, filing history and SRNs.

Feeds the [[strategy-loop]]; stored per case in an encrypted vault ([[privacy-dpdp]]).
